# Combat Progression & Endgame Design — Superseded

**Status:** Archived design direction; not approved for implementation.

This document previously explored a class-based combat RPG and multi-form combat roster. That direction is no longer approved. Tiny Titans is an exploration-first Creature Exploration RPG centered on one personal Tiny Titan per player. A combat system is not required for MVP, danger, progression or replayability.

Do not use the former class roster, combat balance targets, PvP systems or endgame progression proposals as active requirements.
